# הסדר של חיה

אפליקציית משימות לטלפון: משימות לפי דחיפות, דברים קטנים, משימות קבועות, רעיונות נחמדים, הגרלה וטיימר.

## העלאה
1. ריפו חדש ב-GitHub, והעלאת כל התוכן של התיקייה הזו (כולל התיקייה `icons`) לשורש הריפו.
2. Settings ← Pages ← Source: `Deploy from a branch`, ענף `main`, תיקייה `/ (root)`.
3. אחרי דקה-שתיים האפליקציה זמינה בכתובת `https://<username>.github.io/<repo>/`.

## התקנה בטלפון
- **אנדרואיד (כרום):** לפתוח את הכתובת ← שלוש נקודות ← "התקנת אפליקציה" / "הוספה למסך הבית".
- **אייפון (ספארי):** לפתוח את הכתובת ← כפתור שיתוף ← "הוספה למסך הבית".

## חשוב לדעת
- המשימות נשמרות בטלפון עצמו. בהגדרות (גלגל השיניים) יש "שמירת גיבוי" ו"שחזור מגיבוי".
- עדכון גרסה: מחליפים את `index.html` בריפו. אם שיניתם גם אייקונים, מעלים את המספר ב-`CACHE` בקובץ `sw.js` (למשל `seder-v2`).
